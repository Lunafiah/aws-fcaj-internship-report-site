**On this page**, you will find the detailed worklog for my 9-week AWS FCAJ internship program (from June 1st to July 31st). The capstone project is: Serverless Microservice - Smart QR Attendance API.

Below is a summary of the main tasks completed each week:

**Week 1 (1/6 - 7/6):** [Internship onboarding & topic selection](1.1-week1/)
- Complete internship procedures, understand rules and guidelines
- Find teammates, discuss potential project topics
- Research AWS Serverless architecture concepts

**Week 2 (8/6 - 14/6):** [AWS account setup & basic labs](1.2-week2/)
- Create AWS Free Tier account and configure AWS Budgets
- Complete $100 credit tasks: Launch EC2, setup Budget, create Lambda web app, create Aurora/RDS database
- Study IAM Access Control and install AWS CLI + CDK
- Install Kiro IDE, explore CloudFormation
- Attend Meetup event (DevOps, Data Analytics, URL Shortener)
- Finalize project: Serverless Microservice - Smart QR Attendance API

**Week 3 (15/6 - 21/6):** [CDK workshop & architecture design](1.3-week3/)
- Complete CDK Basic workshop
- Study AWS architecture diagramming with draw.io
- Start CDK Advanced workshop (Cross-stack references)
- Setup report site (Hugo + GitHub Pages)

**Week 4 (22/6 - 28/6):** [VPC networking & report site](1.4-week4/)
- Complete Amazon VPC and AWS Site-to-Site VPN workshop
- Complete EC2 Cost Optimization with Lambda workshop
- Push report site to GitHub

**Week 5 (29/6 - 5/7):** [Serverless backend development](1.5-week5/)
- Study Serverless patterns: Lambda + API Gateway + DynamoDB
- Begin BK-Sync backend development using AWS SAM
- Design DynamoDB table schemas for attendance data
- Study Amazon Cognito for user authentication

**Week 6 (6/7 - 12/7):** [API integration & authentication](1.6-week6/)
- Integrate API Gateway with Lambda functions
- Implement user authentication with Amazon Cognito (Admin, Teacher, Student roles)
- Configure AWS Secrets Manager for HMAC key storage
- Study cost optimization strategies and resource tagging

**Week 7 (13/7 - 19/7):** [Backend feature development](1.7-week7/)
- Implement pagination for Admin listUsers API
- Implement get student attendance history (UC-S04)
- Implement auto-close expired sessions (FR-12)
- Submit pull requests for code review

**Week 8 (20/7 - 26/7):** [Testing pipeline & monitoring](1.8-week8/)
- Build automated integration testing pipeline for implemented features
- Complete EC2 fundamentals lab
- Setup CloudWatch alarms and monitoring dashboard
- Configure SNS alerts for system health

**Week 9 (27/7 - 31/7):** [Project finalization & report](1.9-week9/)
- Final testing and bug fixes for BK-Sync system
- Complete internship report site content
- Prepare presentation slides and record demo video
- Review and wrap up all documentation
